# 机械臂模块确认命令

> 适用对象：STM32F407 三电机机械臂模块  
> CAN：500 kbps，扩展帧，数据帧  
> 当前固件：每次上电重新绑定组号和臂位，绑定只保存于 RAM

## 1 当前实现摘要

当前工程采用：

```text
1块F407 = 1个机械臂 = 3个电机
5个机械臂 = 1组 = 15个电机
所有F407烧录同一份固件
```

模块确认包括以下四部分：

1. 上电后发送 UID 未编号宣告。
2. 上位机发送“组号+臂位绑定”帧。
3. 模块回复组号确认和臂位确认，绑定成功后允许运动。
4. 上位机可发送状态查询，确认电机1~3是否就绪。

当前固件配置：

```text
UIDASSIGN_SESSION_MODE = 1
```

因此每次断电重启后：

```text
不恢复历史SEG
必须重新接收UID宣告
必须重新绑定组号和臂位
```

## 2 组内AXIS映射

组内每5个机械臂共用 AXIS 1~15：

| 组内机械臂位置 | 本臂电机 | 占用全局AXIS |
|---:|---|---|
| 机械臂1 | 电机1~3 | 1~3 |
| 机械臂2 | 电机1~3 | 4~6 |
| 机械臂3 | 电机1~3 | 7~9 |
| 机械臂4 | 电机1~3 | 10~12 |
| 机械臂5 | 电机1~3 | 13~15 |

第一组：

```text
SEG=0
完整AXIS范围=1~15
```

第二组：

```text
SEG=1
完整AXIS范围=1~15
```

组号和组内臂位共同决定本F407负责的3个全局AXIS。

## 3 上电UID宣告

未绑定机械臂周期发送UID宣告：

```text
ID范围：0x15BC0080 ~ 0x15BC00BC
DLC：8
DATA：设备类型 + UID低56位
```

数据格式：

```text
byte0    = 设备类型，1=主控
byte1..7 = UID低56位，大端
```

实测示例：

```text
ID   = 0x15BC00A4
DLC  = 8
DATA = 01 52 50 06 00 20 00 49
```

解析：

```text
设备类型 = 0x01
UID低56位 = 52 50 06 00 20 00 49
```

上位机发送绑定时，只使用后面的7字节 UID56，不包含设备类型。

## 4 组号+臂位绑定

绑定帧：

```text
ID：0x15BC0020
DLC：8
DATA：UID低56位 + 绑定字节
```

绑定字节：

```text
绑定字节 = (SEG << 3) | (ARM - 1)
```

取值范围：

```text
SEG = 0..14
ARM = 1..5
```

### 4.1 第一组绑定字节

| 位置 | SEG | ARM | 绑定字节 |
|---|---:|---:|---:|
| 第1组机械臂1 | 0 | 1 | `00` |
| 第1组机械臂2 | 0 | 2 | `01` |
| 第1组机械臂3 | 0 | 3 | `02` |
| 第1组机械臂4 | 0 | 4 | `03` |
| 第1组机械臂5 | 0 | 5 | `04` |

第二组机械臂1：

```text
(1 << 3) | (1 - 1) = 0x08
```

### 4.2 实测绑定示例

实测UID：

```text
52 50 06 00 20 00 49
```

绑定为第1组、机械臂1：

```text
ID   = 0x15BC0020
DLC  = 8
DATA = 52 50 06 00 20 00 49 00
```

## 5 绑定确认

绑定成功后，模块发送两帧确认。

### 5.1 组号确认

```text
ID：0x15BC0050
DLC：8
DATA：UID低56位 + ((SEG << 4) | Result)
```

成功：

```text
Result=0
```

第1组绑定成功实测：

```text
ID   = 0x15BC0050
DATA = 52 50 06 00 20 00 49 00
```

最后字节：

```text
高4位0 = SEG=0，第1组
低4位0 = 绑定成功
```

### 5.2 臂位确认

```text
ID：0x15BC0060
DLC：8
DATA：UID低56位 + ((ARM << 4) | AxisBase)
```

臂位与 AxisBase：

| ARM | AxisBase | 本臂AXIS |
|---:|---:|---|
| 1 | 1 | 1~3 |
| 2 | 4 | 4~6 |
| 3 | 7 | 7~9 |
| 4 | 10 | 10~12 |
| 5 | 13 | 13~15 |

第1组、机械臂1绑定成功实测：

```text
ID   = 0x15BC0060
DATA = 52 50 06 00 20 00 49 11
```

最后字节 `0x11`：

```text
高4位1 = 机械臂1
低4位1 = 起始AXIS=1
```

注意：`0x15BC0060` 是模块发送的应答，上位机只能接收，不能重复发送。

## 6 状态查询

绑定成功后，上位机可以查询模块状态。

广播查询：

```text
ID：0x00000020
DLC：4
DATA：Token uint32，大端
```

示例：

```text
ID   = 0x00000020
DLC  = 4
DATA = 12 34 56 78
```

点名NODE=1查询：

```text
ID：0x00002020
DLC：4
DATA：Token uint32，大端
```

状态查询只用于复核，不替代组号+臂位绑定。

## 7 状态应答

应答ID包含组号：

```text
应答ID = 0x00002060 + (SEG << 18)
```

示例：

| 状态 | 应答ID |
|---|---|
| SEG=0 | `0x00002060` |
| SEG=1 | `0x00042060` |
| SEG=14 | `0x00382060` |
| 未绑定，SEG=15 | `0x003C2060` |

应答固定 DLC=8。

数据格式：

```text
byte0    = 协议版本，当前为1
byte1    = SEG，0xFF表示未绑定
byte2    = (ARM << 4) | AxisBase
byte3    = 电机存在掩码
byte4    = 电机就绪掩码
byte5    = 模块状态
byte6..7 = 请求Token低16位
```

电机存在掩码：

```text
bit0 = 电机1存在
bit1 = 电机2存在
bit2 = 电机3存在
```

当前三电机机械臂正常值：

```text
byte3 = 0x07
byte4 = 0x07
```

模块状态位：

```text
bit0 = SEG+臂位已绑定
bit1 = 允许运动
bit2 = 急停锁存
bit3 = 至少一个轴存在限位/编码器故障
```

第1组、机械臂1、三轴全部正常：

```text
ID   = 0x00002060
DLC  = 8
DATA = 01 00 11 07 07 03 56 78
```

解析：

```text
01      协议版本1
00      第1组
11      机械臂1，起始AXIS=1
07      电机1~3存在
07      电机1~3就绪
03      已绑定，允许运动
56 78   Token低16位
```

## 8 绑定后的运动映射

全局AXIS格式不变：

```text
相对运动ID = 0x04402104 + (SEG << 18) + ((AXIS - 1) << 8)
```

第1组、机械臂1：

| 本臂电机 | 全局AXIS | 相对运动ID |
|---|---:|---|
| 电机1 | 1 | `0x04402104` |
| 电机2 | 2 | `0x04402204` |
| 电机3 | 3 | `0x04402304` |

第1组、机械臂2：

| 本臂电机 | 全局AXIS | 相对运动ID |
|---|---:|---|
| 电机1 | 4 | `0x04402404` |
| 电机2 | 5 | `0x04402504` |
| 电机3 | 6 | `0x04402604` |

模块内部完成映射：

```text
全局AXIS4 -> 本地电机1
全局AXIS5 -> 本地电机2
全局AXIS6 -> 本地电机3
```

ACK、位置反馈、到位、停止、限位和故障事件均使用全局AXIS。

## 9 未绑定保护

未完成组号+臂位绑定时：

```text
不执行普通运动命令
继续处理安全帧、UID领号帧和状态查询
```

如果运动帧进入未绑定模块，返回：

```text
Result=2 基准无效/未绑定
```

绑定成功的同一上电会话内，不需要再次发送状态查询才允许运动。

## 10 异常状态处理

运动命令返回：

```text
Result=2 -> 未绑定，需要重新执行组号+臂位绑定
Result=4 -> 限位或编码器故障锁存，需要对应轴故障复位
Result=5 -> 急停锁存，需要解除急停
```

解除急停：

```text
ID=0x00000004
DLC=1
DATA=01
```

三电机故障复位：

```text
电机1：0x04402114 DATA=01
电机2：0x04402214 DATA=01
电机3：0x04402314 DATA=01
```

## 11 完整操作顺序

```text
1. 只给一个未绑定机械臂上电
2. 接收0x15BC0080~0x15BC00BC的UID宣告
3. 记录DATA中的UID低56位
4. 发送0x15BC0020：UID56 + 组号/臂位绑定字节
5. 检查0x15BC0050：组号及绑定结果
6. 检查0x15BC0060：臂位及起始AXIS
7. 可选发送0x00000020查询电机状态
8. 等待0x00002060+SEG偏移应答
9. 确认电机存在掩码、就绪掩码和模块状态
10. 使用全局AXIS发送运动命令
```

## 12 部署注意事项

1. 同一时间只给一个未绑定机械臂上电确认。
2. 同一SEG下5个机械臂必须绑定不同ARM，禁止出现相同ARM。
3. 每次上电都必须重新绑定组号和臂位。
4. 机械臂移动物理位置后，必须按新位置重新绑定。
5. 当前绑定只保存在RAM，不写Flash。
6. 组号和臂位绑定成功后，UID周期宣告停止。
